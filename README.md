# MyAiS official website — R004

Updated 27 November 2026. Static GitHub Pages site for https://myais.ae/.

## Deployment

The root of the main branch contains index.html, style.css, script.js, assets/, CNAME, robots.txt and sitemap.xml. No build framework, backend, API credentials or database is required. Preserve the CNAME and existing DNS/mail records. GitHub Pages deployment status can be checked in the repository's Actions and Pages settings.

## Public contact

Founder-approved address: contact@myais.ae. The JavaScript configuration and all HTML fallback links must agree. Mailbox delivery is separate from website deployment.

## Public content

- MyAiS is the existing UAE-registered technology company and connected software ecosystem.
- One suite licence covers its applications as available; provider usage, hardware and hosting are distinct.
- S.Ai Mobile is the former MyAiS Mobile Android application. MyAi Mobile is a separate standalone on-device Ai application designed to be free.
- Existing software and demonstrated capabilities are distinguished from ongoing integration and development. WorkConv supports the connected suite, with full cross-application synchronization still being validated.
- MMI is central management; six existing specialised role services are described separately from ATM, AGN and CNC development directions.
- OSI is introduced only as exploratory research. Detailed research methods, architecture, private investment terms and confidential material are excluded.
- Actual S.Ai and former MyAiS Mobile screenshots are retained; the future headquarters image remains labelled as a concept.
- Brand philosophy: Yes to Ai. But Human First.

## R004 artwork and branding

The MyAi Android proof gallery retains its original three screenshots. The approved OSI research artwork is displayed from assets/osi-research-artwork.png when present; the official OSI logo remains in the assets folder. The header and footer use the full triangle from the official MyAiS logo.

Brand rule: always spell Ai with a lowercase i; use many Ai, different Ai or multiple Ai models instead of appending a plural s. Preserve registered product names such as Ai.S, S.Ai and MyAiS.

The official MyAi tagline is "MyAi - Your Ai. Airplane Mode On." The public vision and philosophy are included on the homepage.
